# CharityFlow 🏛️

> **The all-in-one nonprofit operating system** — Simplifying nonprofit management, compliance, and reporting.

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

## 🚀 Overview

CharityFlow is a comprehensive nonprofit operating system replacing 6+ disconnected tools with one intuitive platform. For $79-199/month, small nonprofits get automated Form 990 filing, CPA-grade tax optimization, location-based compliance guidance, donor CRM with fundraising tools, local event management, board governance, and audit-grade security — all in plain language requiring zero accounting knowledge.

**Target Market:** 200K+ small US nonprofits (under $5M annual budget)
**TAM:** $2.1B | **CAGR:** 4.2% | **Dream Score:** 59/100

## 🎯 Problem

Over 200,000 small US nonprofits lack affordable tools purpose-built for their needs. They cobble together legacy accounting tools, spreadsheets, and manual processes — none of which talk to each other. This leads to:
- Missed tax deadlines & jeopardized 501(c)(3) status
- Poor donor retention & failed fundraising events
- Audit nightmares & compliance gaps

## 💡 Solution — 8 Core Engines

| Engine | What It Does |
|--------|-------------|
| 🧾 **CPA-Grade Tax Optimizer** | Protects 501(c)(3) status, UBIT tracking, Form 990 auto-filing, donor tax benefit maximization |
| 🗺️ **Location-Based Compliance** | Auto-detects local laws at signup, compliance roadmap, health score, quarterly law updates |
| 💰 **Donor CRM & Fundraising** | Campaigns, peer-to-peer, auto tax receipts, gift matching |
| 🎪 **Local Event Success Engine** | Venue finder, vendor discounts, permit guidance, event ROI |
| 📋 **Board Governance** | Meeting minutes, voting, document sharing |
| 🔐 **Audit-Grade Security** | Role-based access, immutable logs, smart notifications |
| 📊 **Financial Management** | Plain-language transactions, auto-categorization, bank feeds |
| 📝 **Reporting Engine** | Quarterly reports, Form 990 generation, donor acknowledgments |

## 🏗️ Tech Stack

- **Frontend:** Next.js + Tailwind CSS (responsive web app — PC, Mac, mobile)
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **Payments:** payment processors
- **Hosting:** AWS / Vercel
