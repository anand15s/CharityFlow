# CharityFlow — MVP Web Application Specification

## Overview
Build a Next.js full-stack web application for CharityFlow, a platform designed for small local nonprofits to manage their finances easily and efficiently.

## Core Pages/Routes
- `/dashboard` — Main user dashboard displaying financial summaries and recent transactions
- `/transactions` — Record and categorize new donations and expenses
- `/events` — Manage and view itemized transactions related to specific events
- `/reports` — View and download quarterly financial reports and tax documents
- `/donors` — Donor CRM with giving history and relationship management
- `/compliance` — Compliance Health Score and regulatory roadmap
- `/meetings` — Board meeting management with minutes and voting
- `/subscription` — Manage subscription settings and billing details
- `/login` and `/signup` — Authentication pages

## User Flows
1. User signs up → auto-detects location → generates Compliance Roadmap
2. From dashboard, add transactions under donations or expenses
3. Tag transactions for events to manage event-based finances
4. Quarterly auto-generated financial report with pre-filled Form 990
5. Manage donors, send auto tax receipts
6. Schedule board meetings, record minutes
7. Monitor Compliance Health Score

## Data Models
- **User**: { id, name, email, passwordHash, role, orgId, subscriptionStatus }
- **Organization**: { id, name, type, budget, state, city, county, fiscalYearEnd }
- **Transaction**: { id, type [donation|expense], amount, date, category, eventId, donorId, immutable: true }
- **Event**: { id, name, description, budget, transactions[], venue, permits[] }
- **Donor**: { id, name, email, givingHistory[], taxReceipts[], notes }
- **Meeting**: { id, date, agenda, minutes, votes[], attendees[] }
- **ComplianceItem**: { id, type, deadline, status, jurisdiction }

## API Endpoints
- `POST /api/auth/login` — User login
- `POST /api/auth/signup` — User registration with location detection
- `GET/POST /api/transactions` — CRUD transactions
- `GET/POST /api/events` — CRUD events
- `GET /api/reports` — Generate/retrieve reports
- `GET/POST /api/donors` — CRUD donors
- `GET/POST /api/meetings` — CRUD meetings
- `GET /api/compliance` — Compliance dashboard
- `POST /api/form990` — Generate Form 990

## Third-party Integrations
- **Stripe** — Subscription billing + donation processing
- **Plaid** — Bank feed integration for auto-categorization
- **IRS E-File API** — Form 990 submission
- **Google Maps API** — Location-based compliance and venue finder
